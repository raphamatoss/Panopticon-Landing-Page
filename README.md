# Panopticon.Landing

Landing page de apresentação do Panopticon. Site estático (HTML + CSS + JS puro), sem build.

```
index.html   # conteúdo
styles.css   # estilos (cores da marca: #2771A1, #F2E8DC, #1C1C1E)
script.js    # animações de entrada e contador do mockup
assets/      # logos/ícone copiados de src/Panopticon.Mobile/Panopticon/assets/images
```

## Rodar localmente

Abra `index.html` direto no navegador, ou sirva a pasta:

```
npx http-server src/Panopticon.Landing -p 5599
```
